# VDEC 单个访问单元取帧延迟

metadata:
- date: 2026-11-08 00:07:54
- kind: runtime
- status: resolved
- repository: /root/libmedia-release
- summary: VDEC 对单包 H.264 码流可能尚未产出首帧

## Symptom

VDEC_SendPacket 成功后第一次 MEDIA_VDEC_GetFrame 超时；将同一编码输出拼接为连续 4 帧后可以取到 320x240 NV12。

## Reproduction

```bash
(cd build/vdec && ./vdec_tutorial venc_out.h264 out.nv12)
```

## Evidence

- 首次运行: VDEC decode timeout
- 修复后: VDEC H.264 packet=511 -> NV12 320x240

## Affected Files

- examples/venc/main.c
- examples/venc/README.md
- examples/vdec/main.c

## Root Cause

MPP 解码器需要完整访问单元/解码流水线填充；单个短包在本示例时序下没有及时产生输出。

## Fix Or Workaround

VENC 教程改为送 4 帧并写连续 packets；VDEC 教程等待最多两次取帧并说明输入必须包含完整访问单元。

## Recurrence Prevention

验证编解码教程时先用多个连续编码帧生成码流，再单独测试单包延迟；始终检查输出文件非空。
